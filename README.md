# 검열국 탈출 (일제강점기 문학 1차시 방탈출)

드라마 「100일의 거짓말」 연계 수업용 HTML 방탈출 게임입니다.

## 파일 구성
| 파일 | 내용 |
|---|---|
| `story.js` | **대사·문구·설정**. 프롤로그(PRO), 에필로그(EPI), 물건 눌렀을 때 한 줄(FLAVOR), 화면 문구(TEXT: 안내·단계 설명·힌트·결과), 제한 시간·비밀번호·시구 카드·압수 문서(CONFIG) |
| `game.js` | 게임 동작 코드 (화면, 단계 진행, 힌트, 교사 패널) |
| `assets.js` | 그림 경로·눈 깜빡임 조각·검열실 물건 좌표 |
| `game.html` | 화면 틀과 디자인(CSS) |
| `img/` | 배경, 캐릭터, 아이콘, 오브젝트 PNG |
| `fonts/` | 갈무리11 글꼴 (SIL OFL 1.1) |
| `build.py` | 위 파일들을 한 장짜리 HTML로 합침 |
| `dist/escape_room.html` | **수업에 쓰는 단일 파일** (크롬북, 폰 어디서든 실행) |

## 고치는 법
1. `story.js`의 대사를 고칩니다.
2. `game.html`을 브라우저로 열어 확인합니다 (VS Code의 Live Server 확장을 쓰면 저장할 때마다 새로고침됩니다).
3. 수업용 파일이 필요하면 `python3 build.py`를 실행해 `dist/escape_room.html`을 만듭니다.

### 대사 형식
```js
{bg:"street", spr:"contact", mood:"side", who:"접선책", text:"대사"}
```
- `bg`: 배경 `gate` `street` `press` (생략하면 앞 장면 그대로)
- `spr`: 인물 `guard` `boss` `contact` (생략하면 인물 없음)
- `mood`: 표정. guard: 생략(화남) `calm` `sus` / boss: 생략(보통) `sus` / contact: 생략(보통) `side` `happy`
- `who`: 말하는 사람 이름. 빈 문자열이면 해설
- `caption`: 사람 없이 화면 가운데 글만 3초쯤 떴다가 저절로 넘어가는 장면 자막. 예) `{bg:"street", caption:"1940년대 초, 경성, 어느 날 새벽"}`
- `choices`: 선택지 `[{t:"보이는 글", goto:"이동할 id"}]`, `id`: 이동 대상 표시, `sus`: 의심도 증가량

### 화면 문구 (TEXT)
단계별 안내 문구, 힌트, 결과 화면 글은 `story.js` 맨 아래 `TEXT`에 화면별로 모여 있습니다. `{분}` `{조}`처럼 중괄호로 된 자리는 게임이 채우니 지우지 마세요.
교사용 패널과 결과 화면의 기록 칸(걸린 시간 등)만 `game.js`에 남아 있습니다.

### 미니게임
- **서랍 (1단계 뒤):** 잡동사니를 눌러 치우고 열쇠를 찾습니다. 물건 이름과 한 줄은 story.js의 TEXT.m1, 위치와 그림은 assets.js의 DRAWER에 있습니다.
- **서류함 (2단계 뒤):** 상관이 서류를 볼 때만 리본을 당깁니다. 문구는 TEXT.m2, 누르는 시간·되감기·패턴 확률·들켰을 때 의심도는 CONFIG.m2에 있습니다. 꾹 눌러야 리본이 당겨집니다.
- **상관 자리 비움 (리본을 꺼낸 직후):** 상관이 나가는 장면입니다. 대사는 story.js의 BOSSOUT에 있습니다.
- **타자기 리본 걸기 (3단계 시 쓰기 직전):** 네 가닥을 같은 색·모양끼리 끌어서 잇습니다. 문구는 TEXT.m3, 틀렸을 때 의심도와 인식 거리는 CONFIG.m3에 있습니다.
- **그림 넣기:** 그림을 img/ 폴더에 넣고 assets.js에 경로를 적으면 임시 그림 대신 나옵니다.
  - 서랍 바닥: DRAWER.bg
  - 서랍 속 물건: DRAWER.items의 각 물건에 s 값
  - 등 돌린 상관: IMG.bossBack


### 교실 TV (teacher.html) — 조별 진행 상황 실시간 보기
- 주소: 게임 주소의 `escape_room.html`을 `teacher.html`로 바꾸면 됩니다 (예: `…/dist/teacher.html`). TV에서 열면 **방 번호**와 학생 입장 QR이 나옵니다.
- 학생은 QR로 들어오거나, 시작 화면의 "교실 TV에 나온 방 번호"에 번호를 넣으면 됩니다. 번호를 비우면 TV에는 안 나오고 게임은 그대로 됩니다.
- TV에는 8개 조의 현재 단계, 남은 시간, 의심도가 나오고, 탈출한 조는 큰 글자 조각이 뜨며 `그날이오면`이 다 모이면 축하 화면이 나옵니다.
- **위장 시 확인 (비밀번호 대신):** 3단계에서 검열을 통과한 시가 TV로 올라옵니다. 그 조 칸에 `시 확인 요청`이 깜빡이고, 위쪽에 `시 확인 대기 N개` 버튼이 뜹니다. 누르면 시가 크게 나오고 **통과** / **다시 쓰기**를 고릅니다.
  - 통과: 학생 화면이 저절로 에필로그로 넘어갑니다 (3초 안).
  - 다시 쓰기: 학생은 3단계로 돌아가 시를 고쳐 다시 냅니다. 새 시가 다시 TV에 올라옵니다.
  - ‘동지만 아는 뜻’은 처음엔 접혀 있고, `동지만 아는 뜻 보기`를 누르면 보입니다.
  - 방 번호 없이 하거나 인터넷이 안 되면 예전처럼 선생님 비밀번호로 엽니다 (문 화면 아래 `TV 연결이 안 될 때`).
- 구조: 학생 게임이 `censor/방번호/groups/조번호`에 상태 한 줄을 4초마다(바뀔 때마다) 보내고(net.js), TV가 그 방을 실시간으로 받습니다. 위장 시와 숨은 뜻은 `censor/방번호/poems/조번호`에, 선생님 판정은 `censor/방번호/verdict/조번호`에 저장됩니다. 학생 이름은 보내지 않습니다.
- 설정: net.js 맨 위 `NET.db`가 Firebase Realtime Database 주소입니다. 보안 규칙은 `firebase-rules.json` 내용을 Firebase 콘솔 → Realtime Database → 규칙에 붙여 넣으세요.
- 방 번호는 비밀번호 역할도 합니다. 반마다 다른 번호를 쓰세요.

### 교사 모드 (확인용 건너뛰기)
아래쪽 **교사용** 버튼에 비밀번호를 넣으면 교사 모드가 켜집니다.
- 오른쪽 아래 **넘기기 ▶**: 문제를 풀지 않고 다음 단계로 넘어갑니다.
- **메뉴 → 바로 가기**: 원하는 단계(1단계, 서랍 게임, 2단계, 서류함 게임, 3단계, 문, 에필로그, 결과 화면)로 바로 갑니다.
- 교사 모드는 그 기기에 기억됩니다. 학생 기기에서는 **메뉴 → 교사 모드 끄기**를 꼭 누르세요.
